# ☕ Grão e Arte

> Unindo a paixão pelo café especial ao universo da arte, cultura e design.

---

## 📋 Sobre o Projeto

O **Grão e Arte** é um projeto criado para conectar apreciadores de cafés especiais e entusiastas de arte e artesanato. A plataforma funciona como um ponto de encontro digital para divulgação de eventos, catálogo de produtos artesanais, artigos sobre métodos de preparo de café e exposição de artistas locais.

---

## 🚀 Funcionalidades

- ☕ **Catálogo de Cafés:** Exploração de grãos especiais, notas sensoriais, origem e métodos de extração recomendados.
- 🎨 **Galeria de Arte:** Espaço dedicado para artistas locais exibirem suas obras, artesanatos e coleções temáticas.
- 📅 **Agenda Cultural:** Programação de workshops, degustações guiadas e exposições.
- 🛒 **Loja Virtual / Pedidos:** Integração para encomenda de cafés frescos e itens artísticos exclusivos.
- 📖 **Blog & Conteúdo:** Dicas sobre o universo do café, entrevistas com artistas e artigos sobre sustentabilidade no cultivo.

## 🔧 Como Executar o Projeto

### Pré-requisitos

Certifique-se de ter instalado em sua máquina:
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (versão 18 ou superior)

### Passo a passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/grao-e-arte.git
   ```

2. **Acessar a pasta do projeto:**
   ```bash
   cd grao-e-arte
   ```

3. **Instalar as dependências:**
   ```bash
   npm install
   ```

4. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. Abra o navegador e acesse: `http://localhost:3000` (ou a porta indicada no terminal).
